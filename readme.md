# 💱 Currency Converter

A simple and interactive Currency Converter web application that allows users to convert one currency into another using real-time exchange rates.

## 🚀 Features

* Convert currencies using exchange rates fetched from an API.
* Supports multiple currencies.
* Displays country flags for selected currencies.
* Automatically calculates the converted amount.
* Simple and user-friendly interface.

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Currency Exchange Rate API
* Font Awesome

## 📂 Project Structure

```text
Currency-Converter/

```

## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/AkhileshYadav117/Currency-Converter.git
   ```

2. Open the project folder in VS Code.

3. Run `index.html` using Live Server.

4. Select the currencies, enter the amount, and click **Get Exchange Rate**.

## 🌐 API

This project uses the [Currency API](https://github.com/fawazahmed0/exchange-api) to fetch exchange rates.

## 📌 Purpose

This project was created to practice HTML, CSS, and JavaScript concepts, including DOM manipulation, event handling, and API integration.
